Search for and select the recipe named "Decoration" in any vanilla production building to make it endlessly loop its animation.

If you enjoy my work, please consider donating to my [completely optional tip jar](https://ko-fi.com/robb4).

Unlock the recipe for free in HUB Tier 1.

- **The recipe does not appear in the picker unless searched for by name!** This is a consequence of the recipe having no output product.
- If the machine would normally change its visuals based on the color of fluids in a recipe, the color white will be used instead.
- The machine still consumes its normal power amount, although you can underclock it to reduce this
- The recipe only consumes 0-1 MW when running in variable power consumers
- Somersloops and Power Shards can be installed to change the visuals (gas plumes, animation slowdown/speedup)
